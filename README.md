# 💱 CurrencyFlow – Currency Converter

CurrencyFlow is a simple and modern **Currency Converter Web App** that allows users to convert an amount from one currency to another quickly and easily.

## ✨ Features

* 💱 Convert currencies easily
* 🔄 Swap From/To currencies
* 💰 Enter custom amount
* 📊 Display converted amount
* 🌍 Support for multiple currencies
* 📱 Responsive and user-friendly design
* 🎨 Modern and clean interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Exchange Rate Data/API

## 🚀 How to Use

1. Open the CurrencyFlow project.
2. Select the currency you want to convert **From**.
3. Select the currency you want to convert **To**.
4. Enter the amount.
5. Click the **Convert** button.
6. The converted amount will be displayed.
7. Use the **Swap** button to switch the currencies.

## 🔄 How Conversion Works

The application gets the selected currencies and amount, finds the exchange rate, and then calculates the converted value.

```text
User enters amount
        ↓
Select From Currency
        ↓
Select To Currency
        ↓
Get Exchange Rate
        ↓
Calculate Conversion
        ↓
Display Result
```

## 📌 Example

```text
Amount: 100
From: USD
To: EUR

Result:
100 USD → converted EUR amount
```
